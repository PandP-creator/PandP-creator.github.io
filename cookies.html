2. What Are Cookies?

Cookies are small text files stored on your device by websites. Similar technologies may store preferences in your browser or help website operators understand how visitors use their services.

3. How Cookies and Similar Technologies Are Used

Our website may use the following categories:

  • Essential technologies: Support website security, navigation, and basic functionality.
  • Preference technologies: Remember choices you make on the website.
  • Analytics technologies: Help us understand website traffic and improve our content, where analytics tools are installed.
  • Marketing technologies: Help measure advertising performance or support advertising, if marketing services are installed.

We will seek consent for non-essential cookies and similar technologies where required by applicable law.

4. GitHub Pages Hosting

Our website is hosted using GitHub Pages, a static website hosting service. GitHub states that it logs and stores visitors' IP addresses for security purposes. This hosting-related processing is separate from any optional analytics or advertising tools we may add.

For more information, please review the GitHub Privacy Statement.
